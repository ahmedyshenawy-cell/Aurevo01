# موقع اوريفيو — Aurevo

موقع ستاتيك (HTML + CSS + JS) بدون أي سيرفر، جاهز للنشر على **GitHub Pages**.
بالألوان البيرجاندي وخط **Thmanyah Sans**.

## الرفع على GitHub Pages

1. اعمل Repository جديد على GitHub (مثلاً `aurevo`) واخليه **Public**.
2. ارفع كل محتويات الفولدر ده (مش الفولدر نفسه) — لازم `index.html` يبقى في الجذر.
   - من الموقع: **Add file ← Upload files** واسحب كل الملفات والفولدرات.
   - أو من الترمنال:
     ```bash
     git init
     git add .
     git commit -m "Aurevo website"
     git branch -M main
     git remote add origin https://github.com/USERNAME/aurevo.git
     git push -u origin main
     ```
3. من **Settings ← Pages**: اختار **Deploy from a branch**، الفرع `main`، والفولدر `/ (root)` ← **Save**.
4. بعد دقيقة الموقع يبقى على: `https://USERNAME.github.io/aurevo/`

> دومين خاص؟ من نفس صفحة Pages اكتب الدومين في **Custom domain**.

## لوحة التعديل (admin.html) — الأسهل

افتح `https://USERNAME.github.io/aurevo/admin.html` (أو افتحها من جهازك عبر سيرفر محلي).
- عدّل أي نص أو لينك من الفورم، وشوف النتيجة في المعاينة على الجنب.
- ارفع الصور بزر **رفع صورة** (بتتصغّر تلقائيًا علشان الموقع يفضل سريع).
- ضيف / امسح / رتّب عناصر الشغل والعملاء والباقات والأسئلة.
- اضغط **تحميل الملفات (ZIP)** ← فك الضغط ← ارفع فولدر `data` وفولدر `images` على GitHub (Add file ← Upload files ← Commit).

> الصفحة بتعدّل نسخة على جهازك وبتطلّع الملفات، ومبتنشرش لوحدها. ولو مش عايز حد يشوفها احذف `admin.html` من الـ Repository بعد ما تخلّص.

## التعديل اليدوي (كل حاجة من ملف واحد)

كل النصوص والصور واللينكات في **`data/content.js`** — مش محتاج تلمس HTML ولا CSS.

| عايز تعمل إيه | تعدّل إيه |
|---|---|
| تغيّر رقم الواتساب / الموبايل / الإيميل | `contact` |
| تغيّر صورة في معرض الشغل | `work.items` ← `image` |
| تحط لينك على صورة | `work.items` ← `link` (فاضي `""` = من غير لينك) |
| تغيّر لوجو عميل أو لينكه | `clients.items` ← `logo` / `link` |
| تضيف عنصر جديد | انسخ سطر `{ ... },` والصقه تحته |
| تمسح عنصر | امسح السطر بتاعه |
| تغيّر الباقات / الأسئلة / الأرقام | `packages` / `faq` / `stats` |

### تغيير الصور
- حط الصورة في `images/work/` (للشغل) أو `images/clients/` (للعملاء).
- اكتب مسارها: `image: "images/work/اسم-الصورة.jpg"`
- أو استخدم لينك مباشر: `image: "https://.../photo.jpg"`
- مقاس صور الشغل المناسب: **800×1000** (نسبة 4:5).
- مقاس لوجو العميل: **240×240** مربع.

### اللوجو
استبدل `images/logo.svg` بلوجو اوريفيو الحقيقي (SVG أو PNG، وغيّر الامتداد في `brand.logo` لو PNG).

### الألوان
في أول `css/style.css` تحت `:root` — البيرجاندي الأساسي هو `--wine-700`.

## ملاحظات
