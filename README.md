# موقع اوريفيو (نسخة ملفات مسطّحة — من غير فولدرات)

كل الملفات جنب بعض في مكان واحد، علشان ترفعها من الموبايل على GitHub بسهولة.

## الملفات (16 ملف)
`index.html` · `style.css` · `main.js` · `content.js` · `admin.html` · `admin.css` · `admin.js` · `auth.js` · `gate.js`
`icon.png` · `logo-wide.png` · و5 ملفات خطوط `thmanyahsans-*.woff2`

## الرفع من الموبايل
1. افتح الـ Repository ← **Add file ← Upload files**.
2. اختار **كل** الملفات دي مرة واحدة (من تطبيق Files، حدد الكل) ← **Commit changes**.
3. لازم الـ 16 ملف يظهروا في الصفحة الرئيسية للـ Repository جنب بعض.
4. Settings ← Pages ← Deploy from a branch ← `main` و `/ (root)`.

## التعديل
- افتح `admin.html` على لينك الموقع، عدّل وارفع الصور، واضغط **تحميل الملفات (ZIP)**.
- فك الضغط، وارفع `content.js` والصور (أسماؤها بتبدأ بـ `u-`) بنفس الطريقة (Upload files ← Commit).
- ملف `.nojekyll` اختياري.

## باسورد لوحة التعديل
- الدخول لـ `admin.html` بباسورد. تغييره من زرار **تغيير الباسورد** جوه اللوحة، وبينزّل `auth.js` جديد ترفعه مكان القديم.
- ده حماية بسيطة من المتصفح بتمنع الدخول العادي. الحماية الحقيقية هي حساب GitHub نفسه (فعّل التحقق بخطوتين)، لأن محدش يقدر ينشر تعديل على الموقع من غير ما يدخل عليه.
